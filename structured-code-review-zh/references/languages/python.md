# Python 规则

## 状态与边界

- 禁止非故意的可变默认参数，如 `def f(items=[])`；改用 `None` 后在函数内创建。
- 检查类级可变属性、模块级可变全局和闭包循环变量造成的跨调用共享。
- 检查空序列索引、`min/max` 空输入、缺失字典键、零除、边界和异构元素。
- 浮点结果需要容差时不能直接精确比较；先确认业务确实允许误差。

## 异常

- 避免裸 `except:` 和过宽 `except Exception`；捕获实际可能发生的异常。
- 禁止捕获后 `pass` 或转换为成功而没有安全、明确的 best-effort 语义。
- 使用 `raise ... from err` 保留原因；缩小 try 块范围，避免掩盖错误来源。
- 不用 `assert` 校验外部输入，因为优化模式会移除断言。

## 身份与资源

- 字符串、数字、元组等值比较使用 `==`，不要依赖 `is` 的驻留行为。
- 与 `None` 或自定义 sentinel 比较时使用身份比较。
- 文件、socket、锁和数据库连接优先使用 `with`；异常路径也必须释放资源。
- 生成器持有资源时检查迭代提前终止后的关闭行为。

## 异步与并发

- coroutine 必须被 await、调度或返回；检查同步函数误调用 async 函数。
- 阻塞 I/O 不应直接运行在事件循环热路径。
- 检查任务取消、gather 的异常语义、后台任务生命周期和共享可变状态。
- 多进程/多线程环境下模块级缓存和单例状态需要明确隔离与同步。

## 性能

- 确认数据规模和热路径后，再报告循环字符串拼接、列表 membership、重复正则编译。
- 大数据优先生成器、分页或流式处理；避免无必要地一次性物化全部结果。
- 检查 ORM 懒加载造成的 N+1，以及循环内网络/数据库调用。
